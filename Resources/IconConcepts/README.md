# Voice Master 图标候选

六个独立 SVG 源文件，均为 256 × 256 画布，圆角背景、8 px 透明边距，不含外部资源和位图。`MenuBar/` 是逐款简化的 24 × 24 单色版本，使用 `currentColor`。已选定 **D · 声线 V**；正式源文件位于 `../Icons/`，应用与菜单栏均使用该方案。

| 编号 | 文件 | 方向 |
| --- | --- | --- |
| A · 声量跃升 | `A-boost.svg` | 橙色扬声器与向上箭头，直观表达音量放大 |
| B · 独立声轨 | `B-dual-track.svg` | 墨绿底、双组波形，强调分开控制媒体与通话 |
| C · 星环旋钮 | `C-orbit.svg` | 蓝紫旋钮和青色环线，偏音频工具质感 |
| D · 声线 V | `D-wave.svg` | 深紫底、单笔 V 波形，简洁品牌标记 |
| E · 玫瑰推子 | `E-equalizer.svg` | 珊瑚玫红与三根推子，表达独立调音 |
| F · 银白声场 | `F-play.svg` | 银白底、播放三角和声波，偏原生媒体工具 |

`preview.svg` 保留选稿时的矢量对比图，包含 192 px 主图、32 px 缩略图，以及浅色/深色菜单栏单色图形。正式菜单栏图形使用 18 pt 模板图像，并提供 1× / 2× 分辨率。
