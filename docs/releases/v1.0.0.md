# Voice Master 1.0.0

原生 macOS 应用独立音量工具：选择一个媒体应用，将播放增益调至 0–400%。音频只在本机实时处理，不保存、不上传，不修改系统总音量。

## 主要功能

- 双栏界面，支持浅色和深色外观；采用 D「声线 V」应用及菜单栏图标。
- 按应用名称、中文、完整拼音或首字母搜索；常用与最近搜索可固定、删除或清空。
- 为每个应用记住增益，自动迁移旧版设置；重启恢复查询和可稳定识别的应用选择，由用户手动启用。
- 0–400% 增益、软限幅，以及 100%、150%、200% 快捷值；菜单栏可随时停止处理或重新打开窗口。

## 下载与使用

下载本页附件 **`VoiceMaster-1.0.0-macOS-arm64.zip`**；**`SHA256SUMS.txt`** 提供压缩包校验值。

1. 解压，将 **Voice Master.app** 放入「应用程序」后启动。
2. 让浏览器或播放器开始播放，在左侧选择媒体应用。
3. 点击「开启音量调节」，首次使用按系统提示允许录制系统音频。授权入口也可在「系统设置 → 隐私与安全性 → 屏幕与系统音频录制」中找到，名称可能随系统版本变化。
4. 从 100% 开始按需调整；切换应用后重新启用。关闭窗口后仍可从菜单栏打开。

## 支持范围与限制

- 仅提供 **Apple Silicon / arm64** 下载包。本机实测环境为 **macOS 26.5.2**；最低构建目标为 macOS 14.2，其他系统版本尚未验证。
- 应用使用本机 **ad hoc 签名，未使用 Developer ID 签名和公证**。macOS Gatekeeper 可能默认阻止直接打开，请按系统安全提示确认来源后操作，或按照仓库说明自行构建。
- 同时处理一个媒体应用。暂不支持含物理输入通道的默认输出设备，包括部分 USB 音频接口或蓝牙通话模式；AirPods 及受保护流媒体的兼容性仍需实测。
- 连续 15 秒无媒体信号会自动停止，恢复播放后需重新启用；睡眠唤醒后也需手动开启。
- FaceTime、设备切换、权限撤销及异常退出等场景尚未完成逐项验收，不能保证完全关闭 FaceTime 的自动压低。软限幅可能改变高峰值音频的动态。
